# VR 文化遗产沉浸式体验平台
## ART_DIRECTION.md — 全局美术设计规范 V1.0

> 适用范围：本项目全部 Unity 场景、模型、材质、灯光、UI 与视觉特效。
> 本文件为强制规范。所有 AI 生成内容在创建前必须读取本文件，并在完成后按第七章自检。

## 一、项目视觉定位

### 1.1 项目定位

本项目以中华文明发展脉络为叙事主线，以中国世界文化遗产为核心内容，构建具有探索性、沉浸感和文化体验价值的 VR 交互场景。

项目不是传统数字展馆，也不是普通的游戏地图，而是融合文化遗产展示、空间探索、环境叙事与交互体验的沉浸式数字文化体验作品。

### 1.2 核心美术风格

东方风格化数字遗产（Stylized Digital Heritage）

以东方文化审美为基础，结合现代 3D 游戏环境设计语言，对真实文化遗产进行适度艺术化表达。

整体参考方向：

- 高品质风格化 3D 游戏环境。
- 东方传统建筑与自然景观的艺术化表达。
- 手绘质感与现代 3D 渲染相结合。
- 电影化环境光影与空间氛围。
- 具有艺术表现力的色彩与构图。

视觉关键词：**Stylized / Oriental / Atmospheric / Immersive / Painterly / Cinematic / Cultural**

### 1.3 核心设计原则

1. **文化真实性**：建筑结构、文化符号、历史特征必须具有可靠依据。
2. **艺术风格化**：不追求照片级写实，而是通过色彩、材质、光影进行艺术化处理。
3. **空间沉浸感**：优先考虑 VR 用户的空间感知与探索体验。
4. **视觉统一性**：所有场景遵循统一的美术语言。
5. **场景差异性**：不同文化遗产通过环境、色彩、地貌和光影体现自身特色。

## 二、整体视觉风格规范

### 2.1 建模风格

采用中高精度风格化 3D 建模。

要求：

- 保留中国传统建筑的基本结构、比例和标志性构件。
- 建筑轮廓清晰，具有良好的远距离识别度。
- 避免过度简化成低多边形（Low Poly）模型。
- 避免过度复杂的写实模型和无意义的几何细节。
- 建筑细节采用适度提炼的艺术化表达。
- 自然环境允许适当夸张地形、植被和空间比例。

建筑建模应优先保证文化特征的准确性，而不是为了美观随意改变遗产形态。

### 2.2 材质风格

采用柔和、细腻、具有一定手绘感的风格化材质。

推荐：

- Stylized PBR Materials
- Hand-painted Textures
- Subtle Surface Details
- Soft Roughness Variation
- Natural Color Gradients

| 对象 | 材质表现 |
| --- | --- |
| 石材 | 具有适度纹理变化，避免塑料感 |
| 木材 | 保留木纹，色彩温润，避免过度写实 |
| 墙体 | 柔和的表面肌理，适当色彩变化 |
| 屋顶 | 层次清晰，避免过度光滑 |
| 土地 | 自然色彩渐变，具有细腻颗粒感 |
| 水体 | 具有柔和反射和适度透明感 |
| 植被 | 轮廓经过艺术化处理，色彩自然 |

禁止：

- 大面积纯色无纹理材质。
- 高反射塑料质感。
- 过度金属化。
- 材质粗糙、贴图模糊。
- 不同模型之间明显的材质风格冲突。

### 2.3 色彩规范

整体采用低至中等饱和度的东方自然色彩体系。

基础色彩：

- 暖灰色
- 米白色
- 沙土色
- 岩石灰
- 木质棕
- 青灰色
- 植物绿

局部强调色：

- 朱砂红
- 石青色
- 石绿色
- 琥珀金
- 陶土橙

色彩使用原则：

1. 环境色彩负责建立氛围。
2. 建筑色彩负责体现文化特征。
3. 重点交互对象可以适当提高饱和度。
4. 不同场景拥有独立的主题色。
5. 避免高饱和度颜色大面积堆叠。
6. 避免统一套用橙黄色滤镜。

### 2.4 光影规范

采用电影化风格化照明。

推荐：

- 柔和的 Directional Light。
- Ambient Lighting。
- Baked Global Illumination。
- Subtle Volumetric Lighting。
- Soft Shadows。
- Atmospheric Fog。

要求：

- 光影需要体现空间纵深。
- 重要建筑和文化对象应有明确视觉焦点。
- 使用自然光线塑造时间与空间氛围。
- 避免过曝、死黑和强烈的游戏特效。
- 避免大面积霓虹灯和科技蓝光。
- 体积光应适度，不应影响 VR 用户视觉舒适度。

## 三、五大文化遗产场景视觉规范

五个场景必须遵循统一的整体美术风格，但拥有不同的环境气质。

### 3.1 良渚古城遗址

主题：起源、早期城市与社会组织。

视觉关键词：自然、原始、湿地、文明萌芽、神秘。

色彩方向：

- 湿地青绿
- 土壤棕
- 石材灰
- 柔和金色

场景设计：

- 展现早期城市聚落与水利系统。
- 强调自然地貌与人类活动的关系。
- 使用湿地、河流、草木等环境元素。
- 展现良渚古城外围水利设施和城址空间。
- 玉器作为重要文化符号，可以通过独立交互展示。

光影：柔和晨光、薄雾、自然环境光。

避免：过度奇幻化、仙侠化、神庙化。

### 3.2 秦始皇陵

主题：统一国家、制度与古代工艺。

视觉关键词：厚重、庄严、秩序、地下空间、历史纵深。

色彩方向：

- 陶土棕
- 暗赭色
- 青铜绿
- 岩石灰
- 暗金色

场景设计：

- 以秦陵历史空间和考古资料为依据。
- 重点表现兵马俑阵列的规模与秩序。
- 突出陶俑、兵器、车马等文化遗产元素。
- 可以设计具有探索感的考古展示空间。
- 重要文物可设置独立观察与信息交互。

光影：低照度环境、局部暖光、方向性光影。

避免：恐怖游戏氛围、地下城风格、过度玄幻化。

### 3.3 敦煌莫高窟与陆上丝绸之路

主题：文明交流、艺术与信仰。

视觉关键词：沙漠、石窟、壁画、光影、色彩、文明交流。

色彩方向：

- 敦煌赭红
- 沙漠金
- 石青
- 石绿
- 米白
- 暖灰

场景设计：

- 展现莫高窟崖壁与洞窟空间。
- 壁画色彩和纹样是重要视觉资产。
- 洞窟内部突出壁画的艺术表现。
- 外部展现戈壁、沙丘和丝绸之路环境。
- 可以通过光线引导用户探索不同洞窟。
- 壁画中的人物、乐舞、飞天等元素可以成为互动内容。

光影：洞窟内外形成明显明暗对比，外部采用柔和沙漠光照，内部采用克制的局部照明。

避免：将敦煌简单处理成金色宫殿；随意使用现代霓虹色和不符合历史依据的建筑。

### 3.4 泉州：宋元中国的世界海洋商贸中心

主题：海上贸易与多元文化。

视觉关键词：海洋、港口、商贸、开放、多元文化。

色彩方向：

- 海洋蓝
- 青瓷绿
- 暖白
- 木质棕
- 朱砂红

场景设计：

- 展现古代港口、船舶和贸易空间。
- 适当表现城市与海洋的空间关系。
- 展现具有代表性的宗教建筑和历史遗迹。
- 通过商品、航海工具、船舶等展示海上贸易。
- 体现不同文化交流融合的历史特征。

光影：明亮自然光、海面反射、柔和天空光。

避免：现代海滨旅游城市风格；将历史港口处理成现代商业街。

### 3.5 北京中轴线

主题：传统都城秩序与中华文明空间观念。

视觉关键词：对称、庄严、秩序、轴线、空间层次。

色彩方向：

- 宫墙红
- 琉璃金
- 青灰色
- 米白色
- 石材灰

场景设计：

- 强调南北中轴线的空间关系。
- 突出建筑群的层次、对称和比例。
- 展现重要建筑之间的空间联系。
- 可以采用俯瞰视角辅助理解城市布局。
- 重点建筑允许近距离观察。

光影：清晰的自然光、柔和阴影、具有仪式感的空间照明。

避免：过度卡通化；随意改变建筑比例与空间布局。

## 四、场景构图与空间设计

### 4.1 空间设计

场景需要具备明确的空间层次：

- **前景**：植被、石材、道路、局部环境物件。
- **中景**：主要建筑、文化遗产主体、交互对象。
- **远景**：山体、天空、地貌、城市轮廓。

场景不能只有一个孤立的建筑模型。需要通过环境资产建立完整的空间体验。

### 4.2 场景视觉焦点

每个场景必须具有：

1. 一个主要视觉中心。
2. 若干次级文化展示对象。
3. 清晰的探索路线。
4. 明确的空间入口和出口。
5. 具有辨识度的环境背景。

### 4.3 环境资产

根据场景主题配置：

- 地形与地貌。
- 植被与自然元素。
- 建筑群与环境建筑。
- 道路、石阶和地面。
- 历史生活物件。
- 文化遗产相关装饰元素。

避免无意义地堆积模型。

## 五、VR 交互界面美术规范

### 5.1 UI 设计风格

采用轻量化、文化感、空间融合的 UI 设计。

视觉关键词：**Minimal / Elegant / Oriental / Immersive / Clear**

要求：

- UI 不应破坏场景沉浸感。
- 信息面板采用简洁的排版。
- 文字具有足够的可读性。
- 重要交互按钮需要明确的视觉反馈。
- UI 可以采用半透明、柔和边框和适度装饰纹样。
- 交互元素应与文化主题建立联系。

### 5.2 UI 禁止事项

- 不使用大量悬浮科技面板。
- 不使用赛博朋克霓虹风格。
- 不使用过多蓝色发光线框。
- 不使用密集文字面板。
- 不使用传统 PC 游戏式复杂 HUD。
- 不让 UI 长时间遮挡主要文化遗产。

### 5.3 交互反馈

交互反馈可以采用：

- 柔和高亮。
- 轻微缩放。
- 轮廓描边。
- 渐变显现。
- 声音反馈。
- 简洁的文化信息提示。

避免强烈闪烁、频繁粒子爆发和快速镜头运动。

## 六、Unity 技术实现建议

### 6.1 渲染管线

优先使用 Unity URP。保持所有场景使用统一的渲染管线和材质体系。

### 6.2 渲染风格

优先采用：

- Stylized PBR。
- Hand-painted Texture。
- Gradient-based Environment。
- Soft Lighting。
- Atmospheric Rendering。

不强制所有模型使用同一种 Shader，但必须保持视觉统一。

### 6.3 后处理

适度使用：

- Color Grading。
- Ambient Occlusion。
- Bloom。
- Depth of Field（仅用于非实时观察或特殊展示，不建议作为 VR 常驻效果）。

VR 场景应优先保证稳定帧率和视觉舒适度。

### 6.4 性能要求

- 优先使用合理的模型面数。
- 使用 LOD 管理远近模型。
- 合理使用 Occlusion Culling。
- 大型静态场景优先考虑烘焙光照。
- 合理管理贴图分辨率。
- 避免不必要的实时阴影。
- 所有视觉效果必须考虑 VR 双眼渲染的性能成本。

## 七、AI 辅助开发的强制约束

本文件是整个 Unity 项目的全局美术规范。所有 AI 生成的模型、材质、场景、灯光、UI 和视觉效果均必须遵循本规范。

### 7.1 生成前要求

在创建新场景前：

1. 读取本文件。
2. 检查现有项目的材质和渲染设置。
3. 确认当前场景所属文化遗产主题。
4. 遵循对应场景的色彩与空间规范。
5. 优先复用已有的公共美术资源。

### 7.2 生成过程要求

- 不得擅自改变整体美术风格。
- 不得将风格化场景改成照片级写实。
- 不得默认采用 Low Poly 风格。
- 不得默认采用赛博朋克或科幻展馆风格。
- 不得使用与文化主题不符的装饰元素。
- 不得为了视觉效果随意改变遗产建筑结构。
- 不得在不同场景之间随意切换渲染风格。

### 7.3 生成后检查

每次完成场景或重要资产后，检查：

- 是否符合东方风格化数字遗产定位？
- 是否具有统一的材质质感？
- 色彩是否符合对应场景规范？
- 光影是否自然？
- 建筑是否保留文化特征？
- 空间是否具有纵深？
- 是否满足 VR 视觉舒适度？
- 是否与其他场景保持统一的艺术语言？

如果不符合，应优先调整材质、灯光、色彩和模型表现，不要直接增加更多装饰元素。

## 八、最终视觉目标

整个项目应呈现为一套具有统一东方审美、艺术表现力和文化辨识度的风格化数字遗产世界。

用户进入场景后，应感受到：

1. 这是一个具有东方文化气质的沉浸式数字世界。
2. 每处文化遗产都具有独特的空间氛围。
3. 建筑与环境具有艺术化表现，但仍能识别真实文化遗产。
4. 场景具有探索价值，而不只是静态展示。
5. 不同场景之间保持统一的视觉品质。

**最终目标：让文化遗产成为一个可以进入、探索和感知的风格化数字世界。**
